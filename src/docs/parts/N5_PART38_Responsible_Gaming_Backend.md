# N5 Part 38 — Responsible Gaming Backend

Server-authoritative foundation for session reminders, deposit/loss limits, take-a-break and self-exclusion controls.

Controls must be enforced by backend payment/game/session services, not merely displayed in the mobile UI.
Exact limits, durations, cooling-off rules and legal notices remain jurisdiction/provider dependent.
Never allow a client to bypass or directly edit these controls.
