# N5 Part 77 — Account Statement & Transactions API Integration

Defines the player-facing contract for the N5 Account Statement screen.

Includes date-range totals for deposits, play, withdrawals, platform withdrawal fees and bonuses, plus separate deposit and withdrawal history.

No round-by-round game history is required by this contract. Financial data is server-authoritative and must be derived from the auditable ledger/transaction records.
